# Simple Kiosk Player v0.11.0

Sealed-enclosure LAN operations release.

## Highlights

- Optional `management.autoStart` starts LAN management automatically after a valid config loads.
- Optional local fixed admin password in `config.json`; default installs still use the temporary tablet code.
- New LAN Device control buttons: Apply config now, Black screen now, Allow sleep now, Resume schedule.
- Schedule saves now apply immediately through LAN control, useful when the tablet screen cannot be touched.
- Manual overrides are runtime-only and higher priority than schedules until Resume schedule is used.
- Schedule time inputs keep strict `HH:mm` validation with clearer browser-side guidance.

## Tested Android Versions

- Samsung SM-T331C, Android 4.4.2 / API 19: prior smoke tests covered playback, scheduling, sleep/wake behavior, upload, previews, and LAN editor. v0.11.0 should be re-smoke-tested on this target before field deployment.
- OPPO Find X8 Pro, ColorOS 16: user smoke-tested app launch and playback on the v0.9.x/v0.10.x line.
- Huawei DBY-W09, HarmonyOS 4.2.0: user smoke-tested app launch and playback on the v0.9.x/v0.10.x line.

## Notes

- Sleep-after-silent and wake behavior varies by vendor firmware. Test the target device, or use black silent mode when wake reliability matters.
- Fullscreen/immersive behavior on notched, punched, or gesture-only devices is not comprehensively covered.
- LAN management is intended for trusted local networks; this release does not add cloud services, accounts, or HTTPS.
