# Simple Kiosk Player v0.8.1

This release adds the first signed APK publishing setup for Simple Kiosk Player.

## Changes

- Adds release APK signing configuration.
- Adds a local `keystore.properties` template while keeping real signing secrets out of Git.
- Keeps release builds from accidentally producing or publishing an unsigned APK when signing config is missing.
- Disables only the Google Play target-SDK lint error for release builds because this project is distributed outside Play and intentionally targets Android 4.4 / API 19 for old tablet compatibility.

## Tested Android Versions

- Samsung SM-T331C, Android 4.4.2 / API 19: previous v0.8.0 smoke test covered playback, scheduling, sleep/wake behavior, media upload, media previews, and the LAN management editor. v0.8.1 changes release packaging only.
