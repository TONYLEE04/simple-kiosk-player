# Simple Kiosk Player v0.10.0

## Highlights

- Upgrades the LAN media library for large local collections.
- Supports recursive folders under `/sdcard/SimpleKiosk/media/`.
- Adds best-effort video compatibility warnings for legacy Android tablets.
- Skips videos that prepare without a decodable video track instead of leaving the previous frame visible.

## Media Library

The LAN page now shows media in a table with search, folder/type/risk filters, pagination, and batch actions. Only the current page loads thumbnail previews, which keeps libraries with many images and videos usable.

Media folders are treated as groups. Files such as `media/A-role/image01.png` can be managed as a folder group, and the selected folder can be added to the target schedule in one action.

## Compatibility Warnings

The media table shows metadata such as resolution, duration, fps, codec, H.264 profile/level, and warning status where available.

Warnings are advisory and do not block usage. They flag high-risk files for old Android devices, including 4K-class video, 60fps video, HEVC/H.265, AV1, H.264 level 5.2 or higher, and files whose video dimensions cannot be read.

For Android 4.4-era tablets, prefer MP4 H.264, 720p or 1080p, 30fps, yuv420p, and AAC audio.

## API Notes

- `GET /media` now returns JSON instead of the older tab-separated text list.
- Media endpoints accept safe relative paths below `/sdcard/SimpleKiosk/media/`.
- `POST /upload?name=...&folder=...` can upload into a subfolder.
- `config.json` schema is unchanged, but playlist item `file` values may now include subfolders such as `media/A-role/clip.mp4`.
