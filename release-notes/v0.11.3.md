# Simple Kiosk Player v0.11.3

Wake-from-silent video startup fix.

## Changes

- Correct the v0.11.2 wake recovery path so the video Surface is reset even while the app is still in silent mode during the wake intent.
- Keep the prepare timeout watchdog for stale-but-available TextureView Surfaces.

## Notes

This targets the observed case where pressing Reload config immediately restores playback after a scheduled wake.
