# Simple Kiosk Player v0.11.1

LAN Access settings usability fix.

## Changes

- Rehydrate the Access form from `config.json` whenever the LAN page loads or reloads config.
- Prevent saved `management.autoStart` and `management.password` from reverting to defaults when editing playlists or schedules.
- Add a Save config button inside the Access section so password and LAN auto-start settings can be saved in place.

## Notes

This is a small bug-fix release on top of v0.11.0. It does not change the runtime config schema.
