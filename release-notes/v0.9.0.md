# Simple Kiosk Player v0.9.0

This release improves first-run setup, scheduled playback resilience, LAN playlist editing, batch upload, and long-running stability.

## Highlights

- New first-run setup screen when `/sdcard/SimpleKiosk/config.json` is missing, with clear instructions for the top-left 5-tap maintenance gesture.
- Config reload polling now continues after startup config failures, so a config saved from the LAN page can load without restarting the app.
- Scheduled playlists are kept alive more aggressively and bad media items are skipped instead of stopping the whole loop.
- Image playback now clears old bitmaps and handles decode out-of-memory failures without crashing the app.
- `logs/player.log` rotates at 1 MB and keeps one backup at `logs/player.log.1`.
- LAN management page supports queued multi-file upload.
- LAN management page supports `playlistPresets` saved in `config.json`; applying a preset copies it into the selected schedule.

## Tested Android Versions

- Samsung SM-T331C, Android 4.4.2 / API 19: smoke-tested playback, scheduling, sleep/wake behavior, media upload, media previews, and the LAN management editor.
- OPPO Find X8 Pro, ColorOS 16: smoke-tested app startup and playback.
- Huawei DBY-W09, HarmonyOS 4.2.0: smoke-tested app startup and playback.

## Cautions

- Sleep/wake behavior has not been verified on every newer device. Test `screen: "allowSleep"` on the actual deployment device, or use `screen: "black"` to avoid depending on wake behavior.
- Fullscreen and immersive behavior has not been fully verified on phone-style full-screen, cutout, or curved-screen devices. Prefer conventional tablet displays for kiosk deployments unless the target device has been tested.

## Compatibility Notes

- `minSdk 19`
- `targetSdk 19`
- Java-only Android app using native Android Views.
- Runtime storage remains `/sdcard/SimpleKiosk/`.
