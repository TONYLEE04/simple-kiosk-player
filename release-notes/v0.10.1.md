# Simple Kiosk Player v0.10.1

Small usability update on top of v0.10.0.

## Changes

- Media library folders now appear as a file-manager-style sidebar instead of a folder dropdown.
- The current folder is shown with breadcrumb navigation.
- Uploads can target the current folder by leaving the upload folder input empty.
- Added an "Upload here" shortcut and changed folder insertion to "Add current folder".

## Validation

- `assembleDebug` passed.
- LAN page JavaScript syntax was checked with bundled Node.js.
