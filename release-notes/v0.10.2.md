# Simple Kiosk Player v0.10.2

Small LAN management UI fix on top of v0.10.1.

## Changes

- Long media file names and paths now wrap inside the Name column instead of stretching the full table.
- The media table uses fixed columns and an internal horizontal scroll area when space is tight.

## Validation

- `assembleDebug` passed.
- LAN page JavaScript syntax was checked with bundled Node.js.
