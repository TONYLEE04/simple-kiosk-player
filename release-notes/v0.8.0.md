# Simple Kiosk Player v0.8.0

Simple Kiosk Player is a lightweight offline Android kiosk media player for turning old Android tablets into local looping display screens.

## Highlights

- Schedule-first LAN management editor: playlist items now live inside schedule entries.
- All-day playback uses a `00:00` to `00:00` playlist schedule.
- Local media upload, rename, delete, and thumbnail preview support from the LAN page.
- Optional silent schedules can let Android turn off the LCD backlight and wake for the next playback window.
- LAN access protection is enabled by default while the management server is running.
- Project license is now GNU GPL v3.0 or later (`GPL-3.0-or-later`).
- The LAN management page includes the optional official Keep Android Open banner when the browser has internet access.

## Tested Android Versions

- Samsung SM-T331C, Android 4.4.2 / API 19: smoke-tested playback, scheduling, sleep/wake behavior, media upload, media previews, and the LAN management editor during the v0.8.0 development cycle.

## Compatibility Notes

- `minSdk 19`
- `targetSdk 19`
- Java-only Android app using native Android Views.
- No AndroidX, Kotlin, Jetpack Compose, Google Play Services, account system, telemetry, or cloud dependency.
- Runtime storage remains `/sdcard/SimpleKiosk/`.

## Release Notes

This release is source-first. A signed production APK pipeline has not been added yet; debug APKs can be built locally with `gradlew assembleDebug` for device testing.
